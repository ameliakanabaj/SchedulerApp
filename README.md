## docker

Uruchamiamy frontend, backend oraz bazę danych jednym poleceniem:

`docker-compose up --build`

## frontend - Angular (./frontend)

odpalenie lokalne:

`cd frontend/`

` npm i --legacy-peer-deps`

`ng serve`

odpalenie unit test:

`npm run test`
